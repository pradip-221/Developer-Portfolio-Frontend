# Developer Portfolio – Frontend

A modern and responsive personal portfolio website built using React.js, Vite, Bootstrap 5, and custom CSS. The application showcases my profile, technical skills, projects, learning journey, and contact information with authentication and an AI-powered chatbot.

## 🚀 Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Bootstrap 5
- React Router DOM
- Axios
- Vite
- REST API Integration
- JWT Authentication

## ✨ Features

### Portfolio
- Responsive developer portfolio UI
- Personal profile and introduction
- Technical skills showcase
- Projects showcase
- Learning journey section
- Contact section
- GitHub and LinkedIn links
- Dark theme with custom styling

### Authentication
- User registration
- User login
- JWT token storage using localStorage
- Protected portfolio routes
- Welcome animation after successful login
- Navigation after authentication

### AI Chatbot
- AI-powered portfolio assistant
- Groq API integration
- Answers questions about portfolio information

### Backend Integration
- Axios-based API communication
- Spring Boot REST API integration
- Dynamic data fetching for portfolio sections

## ⚙️ Installation and Setup

Clone the repository:

```bash
git clone YOUR_FRONTEND_REPOSITORY_URL
```

Navigate to the project:

```bash
cd portfolio-frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open in browser:

```text
http://localhost:5173
```
